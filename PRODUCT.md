# CipherVault

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
An educational secure file workspace for administrators, employees, and guests. Users authenticate, store encrypted files, control sharing, verify integrity, and inspect audit activity according to their server-enforced roles.

## Capabilities and constraints
The React/Vite website uses the existing Python API and vault security boundary. Preserve password/TOTP enrollment and login, CSRF protection, sessions, role checks, encryption, file operations, audit checkpoints, and monitoring. Guest access remains metadata-only. Do not invent security certifications, client-side encryption, or live operational metrics. The Streamlit interface remains a separate supported demonstration.
